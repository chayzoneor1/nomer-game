ГЕНЕРАТОР ТЕЛЕФОННЫХ НОМЕРОВ — TELEGRAM MINI APP BOT

Что делает этот пакет:
- Команда /start показывает кнопку «🎮 Играть».
- Кнопка открывает игру по адресу https://chayzoneor1.github.io/nomer-game/
- При запуске бот также настраивает кнопку меню Telegram «🎮 Играть».

НАСТРОЙКА В WINDOWS
1. Установи Python 3.11 или новее с сайта python.org. При установке включи Add Python to PATH.
2. Открой файл .env в Блокноте.
3. Замени PASTE_YOUR_BOT_TOKEN_HERE на токен своего бота от @BotFather. Сохрани файл.
4. Дважды нажми start_bot.bat. При первом запуске установятся нужные библиотеки.
5. Открой своего бота в Telegram и отправь /start.

БЕЗОПАСНОСТЬ
- Никому не отправляй токен и не публикуй файл .env.
- Не загружай .env в GitHub. Он добавлен в .gitignore.
- Если токен случайно утёк, отзови его через @BotFather и выпусти новый.

ВАЖНО
Этот пакет запускает Telegram-бота и подключает кнопку Mini App. Сайт игры уже указывает на GitHub Pages.
Python-сервер общего рейтинга из предыдущего архива не запускается этим ботом. Если игра обращается к нему, его нужно отдельно разместить на сервере с HTTPS и настроить API-адрес в игре.
Если кнопка меню не обновилась сразу, перезапусти чат с ботом или проверь меню в Telegram.
