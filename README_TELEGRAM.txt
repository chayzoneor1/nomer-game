ГЕНЕРАТОР ТЕЛЕФОННЫХ НОМЕРОВ — ПАКЕТ ДЛЯ ПОДКЛЮЧЕНИЯ

СОДЕРЖИМОЕ
- index.html — страница игры, которую должен отдавать сервер.
- NomerGame_Fixed.html — та же страница с основным именем файла.
- NomerGame_Leaderboard_Server.py — Flask-сервер и API общего рейтинга.
- requirements.txt — зависимости Python.

ЛОКАЛЬНЫЙ ЗАПУСК В WINDOWS (PowerShell)
1. Установи Python 3.11 или новее.
2. Открой PowerShell в папке проекта.
3. Выполни: py -m venv .venv
4. Выполни: .venv\Scripts\Activate.ps1
5. Выполни: python -m pip install -r requirements.txt
6. В BotFather создай/используй своего бота и скопируй токен. Не отправляй токен в чат и не добавляй его в публичные файлы.
7. В PowerShell задай переменную для текущего окна: $env:BOT_TOKEN='ВСТАВЬ_ТОКЕН_БОТА'
8. Запусти: python NomerGame_Leaderboard_Server.py
9. Открой http://127.0.0.1:8080 для локальной проверки в браузере.

ВАЖНО ДЛЯ TELEGRAM
- Для Mini App нужен публичный HTTPS-адрес. localhost не доступен пользователям Telegram как размещённый сайт.
- Размести эту папку на хостинге с HTTPS и укажи URL Mini App в настройках бота через BotFather.
- Сервер должен работать постоянно; используй постоянный диск для файла базы данных nomergame.sqlite3.
- BOT_TOKEN храни только в переменных окружения на сервере. Никогда не вставляй токен в HTML.
- Рейтинг проверяет Telegram initData на сервере. Однако игровой результат по-прежнему формируется клиентом, поэтому перед публичным запуском античит и серверную обработку игровых действий стоит усилить.
