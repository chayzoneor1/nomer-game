# НомерГрам — проект (игра + сервер + бот)

```
NomerGram/
├── game/index.html     ← Mini App (сам сервер отдаёт его на том же домене, что и API)
├── server.py           ← сервер: сохранения, рейтинг, друзья, карточки, HTTPS на 443
├── bot.py              ← Telegram-бот (одна кнопка меню «Играть»)
├── main.py             ← запускает сервер и бота вместе (для кнопки «Старт» на хостинге)
├── cardgen.py + assets/ ← рисует картинку-карточку номера (нужен Pillow)
├── .env.example        ← пример настроек → скопируй в .env
├── get_cert.sh / renew_cert.sh ← бесплатный HTTPS-сертификат для DuckDNS
└── requirements.txt
```

## Запуск на H1Cloud (твой случай)
1. Загрузи **всё содержимое папки** в корень сервера (папки `game/` и `assets/` не теряй). Старые `server.py`, `bot.py`, `cardgen.py`, `nomergame.db` можно заменить/удалить — новая база называется `nomergram.db`.
2. Создай `.env` по образцу `.env.example` (токен бота, `PORT=443`, `PUBLIC_URL`).
3. **DuckDNS**: в личном кабинете duckdns.org поставь IP сервера (узнать: в консоли `curl ifconfig.me` или `ping de-bots4.h1cloud.net`).
4. **HTTPS (обязательно для Telegram).** Проверь `https://nomergram-bot.duckdns.org/api/health`:
   - открывается — у хостинга уже есть HTTPS, ничего не делай;
   - ошибка сертификата/не открывается — выпусти сертификат: в консоли
     `export DUCKDNS_TOKEN=токен_duckdns` → `bash get_cert.sh nomergram-bot.duckdns.org твоя@почта`
     В `.env` должны быть `SSL_CERT=certs/fullchain.pem` и `SSL_KEY=certs/privkey.pem`. Раз в ~2 месяца: `bash renew_cert.sh`.
5. В панели: **Startup → файл запуска `main.py`**, зависимости из `requirements.txt` (или в консоли `pip install -r requirements.txt`). Нажми **Старт**.
   В консоли должно быть: `НомерГрам: https://...:443` и `✅ Бот @... запущен`.
6. Проверка: `https://nomergram-bot.duckdns.org/api/diag` — видно, настроены ли токен, HTTPS, Pillow и связь с Telegram.
7. Открой бота → кнопка **«Играть»**.

> Если игра у тебя лежит на GitHub Pages — тоже работает: в `index.html` адрес API берётся из `API_DEFAULT` (сейчас `https://nomergram-bot.duckdns.org`). Но проще и надёжнее, когда игру отдаёт сам сервер.

## Что исправлено в этой версии
1. **Синхронизация телефон ⇄ ПК.** Раньше побеждало «последнее по времени на устройстве»: простаивающий ПК с устаревшими данными мог затереть новый прогресс с телефона. Теперь у сохранения есть **версия (rev)**: устройство не может перезаписать данные, если они устарели — вместо этого оно подтягивает свежие. Прогресс подхватывается при открытии, при возврате в приложение и раз в 15 секунд.
2. **Сложность.** Шансы: обычный 94,8% · необычный 4,6% · редкий 0,55% · эпический 0,05% · легендарный 0,004% (с учётом гаранта «Редкий» выпадает примерно раз в 45 прокруток). Есть **гарант**: «Редкий» не позже чем через 60 прокруток, «Эпический» — через 1000. Метки Anonymous/Shadow стали реже. Дорогие номера добиваются крафтом и упорством.
3. Кнопка **«Поделиться»** на экране результата заменена на **«Повтор»**: чистый экран, где номер выпадает заново.
4. **Задания и экономика.** Задания сложнее, награды — умеренные рубли, билеты колеса, талисманы и номера. Пакет энергии: 50 ⚡ за 90 000 ₽. Средняя цена прокрутки (~16 500 ₽ по моей симуляции) ниже стоимости энергии (18 000 ₽ за прокрутку при покупке), так что богатеют те, кто выполняет задания, крафтит и ждёт гарант. Крафт стал рискованным: 85 / 70 / 55 / 40%.
5. **Единоразовая очистка.** Все аккаунты начинаются с нуля один раз (значение `DATA_EPOCH`), дальше прогресс сохраняется. Чтобы сбросить всех ещё раз — поменяй `DATA_EPOCH` в `.env` и перезапусти сервер.
6. **Профиль → Настройки → «Информация об игре» / «Настройки интерфейса»** — отдельные страницы с кнопкой «Назад».
7. **Отправка фото номера.** Цепочка из трёх способов: (1) фото-сообщение в выбранный чат; (2) карточка приходит в чат с ботом — её можно переслать; (3) ссылка с картинкой-превью. Раньше ссылка вела на адрес страницы игры (GitHub Pages), а не сервера, и без `PUBLIC_URL` сервер отказывал — это исправлено.

## Если что-то не работает
- `https://.../api/diag` покажет причину (токен, HTTPS, Pillow, связь с Telegram).
- «Не отправляется фото»: проверь, что `PUBLIC_URL` — это https-адрес сервера и `diag` показывает `cardgen: true`. Способ №2 работает и без публичного адреса, если ты хотя бы раз нажимал /start у бота.
- Токен бота мог попасть в архив при пересылке: если сомневаешься — в BotFather `/revoke` и поставь новый в `.env`.
