ГЕНЕРАТОР ТЕЛЕФОННЫХ НОМЕРОВ — ПОЛНЫЙ ПАКЕТ
================================================

1) СНАЧАЛА ПРОВЕРЬ ССЫЛКУ ИГРЫ
   https://chayzoneor1.github.io/nomer-game/

2) ЗАПУСК TELEGRAM-БОТА В WINDOWS
   - Установи Python 3.11+ с https://www.python.org/downloads/
   - Во время установки отметь "Add Python to PATH".
   - Распакуй этот архив в обычную папку.
   - Скопируй .env.example в файл с именем .env (или запусти start_bot.bat — он создаст файл).
   - Открой .env в Блокноте и вставь токен после BOT_TOKEN=.
   - Сохрани файл и запусти start_bot.bat.
   - Открой бота в Telegram и отправь /start.

3) КАК УСТРОЕНА КНОПКА MINI APP
   bot.py использует GAME_URL=https://chayzoneor1.github.io/nomer-game/
   Игра открывается кнопкой меню «Играть» (её ставит bot.py), кнопки под сообщением больше нет.

4) ФАЙЛЫ
   - bot.py — код Telegram-бота.
   - .env.example — пример настроек; сюда копируется токен в локальном .env.
   - start_bot.bat — установка зависимостей и запуск в Windows.
   - requirements.txt — библиотеки Python.
   - game/ — копии HTML-файлов игры, если они были доступны в исходных файлах.
   - server/ — файлы сервера рейтинга, если они были доступны.
   - extras/ — дополнительные файлы, найденные в прежних архивах.

5) ВАЖНО
   - Не присылай токен бота в чат и не публикуй файл .env.
   - Бот работает, пока запущен start_bot.bat/окно консоли.
   - GitHub Pages публикует только статические файлы. Python-сервер рейтинга
     нужно запускать отдельно на хостинге с поддержкой Python.
   - Этот комплект содержит стартовый код бота и файлы проекта, доступные в
     рабочей среде. Проверь, что сама игра открывается по GAME_URL.
