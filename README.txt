1) pip install -r requirements.txt
2) Скопируй .env.example в .env, впиши токен и GAME_URL (публичный https-адрес сервера, например https://example.com/).
3) Сервер (игра + API + карточки): uvicorn server:app --host 0.0.0.0 --port 8000
   Нужен https-домен (nginx/Caddy/Cloudflare Tunnel) — Telegram Mini App работает только по https.
4) Бот: python NomerGame_FULL_Project/bot.py
   Бот сам ставит кнопку меню «Играть» (слева от поля ввода). Кнопки под сообщениями больше нет.
5) Бот и сервер должны быть запущены вместе и с одним и тем же BOT_TOKEN (по нему считается общий секрет для рефералов).

Что нового в v8
- Крафт: «Номера» → «Крафт». 5 обычных → необычный, 4 необычных → редкий, 4 редких → эпический, 4 эпических → легендарный
  (число номеров — CRAFT в начале скрипта game/index.html). Номера с меткой Anonymous/Shadow не участвуют. Есть задания на крафт.
- Убраны взнос за прокрутку и надпись «убыток». Прокрутка тратит только энергию. В минус можно уйти лишь покупкой
  пакета энергии (ENERGY_PRICE = 130 000 ₽ за 50 ⚡), если выпадали дешёвые номера.
- «Поделиться»: маленькая круглая кнопка на карточке выпавшего номера; в чат уходит фото-карточка этого номера
  (значок оператора, редкость, цена, @бот). Из коллекции — тап по номеру → кнопка со стрелкой.
- Рефералка: 3 активных друга (каждый сделал 3 прокрутки) → гарантированный эпический номер (REF_GUARANTEE в server.py).
  Прогресс виден во вкладке «Задания» и в профиле.
- Исправлено: на новом устройстве с облачным сохранением больше не просит заново регистрироваться (и не затирает прогресс).

Что нового в v7
- «Поделиться» отправляет в выбранный чат фото номера + стоимость + @юзернейм бота (нужен Telegram 8.0+,
  для старых клиентов — запасная ссылка с той же картинкой). Сервер должен быть доступен Telegram по GAME_URL.
- Рейтинг — общий для всех игроков, по капиталу: баланс + стоимость номеров в каталоге. Номера в рейтинге не показываются.
  Капитал считает сервер из сохранения игрока. Чтобы скрыть свой аккаунт из рейтинга: NG_HIDE_IDS=твой_telegram_id
- Рефералка в профиле: кнопка «Поделиться» открывает список чатов с готовым сообщением и ссылкой.
  Друг получает +50 энергии и 25 000 ₽, ты — +30 энергии и 20 000 ₽ за каждого, кто сделал 3 прокрутки,
  плюс бонусы за 3 / 10 / 25 друзей. Значения — в начале server.py (REF_*).
- Задания дают энергию + ₽, билеты колеса, талисман удачи и гарантированные номера.
- Прокрутка стоит 10 энергии и взнос 10 000 ₽ (кейс — 50 энергии и 200 000 ₽); цена номера колеблется вместе с рынком,
  так что можно уйти и в плюс, и в минус. Константы FEE / CASE_FEE / START_CASH — в начале скрипта game/index.html.
- Новый баннер приветствия: пересобрать можно командой  python NomerGame_FULL_Project/cardgen.py

Обновление v9.0-reset (изменения проекта)
- Одноразовая миграция: старое локальное сохранение очищается при первом запуске v9, затем прогресс сохраняется как обычно.
- Сервер синхронизации заменяет сохранение старой версии чистым состоянием v9; новые сохранения не сбрасываются повторно.
- Облачный прогресс подтягивается при запуске и возвращении в приложение; версия сохранения проверяется перед применением.
- Стартовый баланс уменьшен, цены/стоимость номеров и редкость перенастроены; задания стали длиннее.
- Кнопка возле выпавшего номера теперь «Повтор» и очищает результат для следующей прокрутки. Шаринг карточки оставлен в действиях номера/коллекции.
- Ежедневный подарок ограничен 24 часами между получениями; серия продолжается только при входе в следующий календарный день.
- В профиле доступны статистика, настройки интерфейса и полная информация об игре.

Важно: для синхронизации и общего рейтинга нужен работающий server.py и тот же Telegram BOT_TOKEN. При первом открытии v9 старый прогресс будет сброшен один раз.
